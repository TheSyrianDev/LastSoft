Local-first AI, on your own machine.

Four programs that run offline, speak to local model servers, and keep your conversations, notes and money on your own disk. Written in Rust.

Projects

Last AI

the assistant

A desktop app and a terminal client talking to a small local core over localhost. The core holds the team (departments and their workers), the tools, memory and learning, and works with any OpenAI-compatible server or local runtime. Front ends are thin clients of the core's API.

Alpha, 0.1.0 · Linux, Windows · macOS early alpha

LH

the harness

The layer underneath Last AI: the core, the clients, memory, tools, the provider layer and the spend limits. Plain and unopinionated — give it a model and a goal, it runs the turn loop. No downloader, no inference engine.

Ships inside Last AI today

LastEngine

the engine

Inference of its own. One backend trait, several implementations — CUDA, CPU, Vulkan, ROCm, Metal — chosen at startup by probing what the machine can actually do, and able to split layers across CPU and GPU for small cards.

In development

hf-dl

the downloader

Models and datasets from the Hugging Face Hub, with resumable and verified transfers. It is just a downloader, and it works on its own.

v0.4.0-rc.1

Install Last AI

Prebuilt packages for the current alpha are on the releases page. Pick the one for your system.

Debian, Ubuntu

sudo apt install ./LastAI-*.deb

Fedora, openSUSE

sudo rpm -i LastAI-*.rpm

Arch, Omarchy

sudo pacman -U LastAI-*.pkg.tar.zst
lastai-omarchy-setup

Anywhere else

chmod +x Last_AI-*.AppImage
./Last_AI-*.AppImage

Windows and macOS builds are attached to the same release. From source it is cargo build --release, which needs a Rust toolchain and takes a few minutes the first time.
