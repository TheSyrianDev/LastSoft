The studio, and the three parts under it

  1. P-01

    Last AI

    The studio. A desktop app and a terminal client (la) speaking to a small local core (lastaid) over localhost. The core holds the team of departments and workers, the tools, memory and learning. Any OpenAI-compatible server or local runtime will do.

    0.1.0-alpha.1
  2. P-02

    LastHarness

    The harness underneath: the core, the clients, memory as Markdown you can read, tools behind permission rules, the provider layer, the spend limits. Give it a model and a goal and it runs the turn loop. No downloader, no inference engine.

    inside Last AI
  3. P-03

    LastEngine

    Inference of its own. One backend trait, several implementations — CUDA, CPU, Vulkan, ROCm, Metal — chosen at startup by probing the hardware, with layers split across CPU and GPU for small cards.

    in development
  4. P-04

    hf-dl

    Models and datasets from the Hugging Face Hub, with resumable and verified transfers. It is just a downloader, and it works alone.

    v0.4.0-rc.1

Three things it will not do

Sign you in
There is no account, no telemetry endpoint, no billing behind a key. Model calls go to the server you named, with the key you gave.
Rewrite your prompt
Learned rules, style and skills are separate blocks added after the base prompt. Every version is kept, and anything applied without asking is logged so you can undo it.
Hold your keys in a file
Secrets live in the OS store — Secret Service, Keychain, Credential Manager. The config holds a reference like secret:openrouter, never the value.

Get it

Prebuilt for Linux, Windows and macOS, with a script for Linux that works out which distribution you are on before it installs anything.
