Model-Downloader

A downloader in Rust for models and datasets, wherever they live: the Hugging Face Hub, ModelScope, and — opt-in, over BitTorrent — Pirate Face. Segmented, resumable transfers with verification, a queue that keeps running after you close the terminal, and no opinion about what you do with the files.

Beta. It has tests and it works, but it has had little use outside the author's machine.

Install

cargo install --path crates/hfd-cli      # needs Rust 1.88 or newer

Two binaries are installed, mdl and Model-Downloader. They are the same program.

Download something

mdl download <repo-id | hf:// URI | web URL> [paths...]

mdl download Qwen/Qwen3-0.6B --include "*.safetensors" --local-dir ./model
mdl download <repo> <file.gguf> --local-dir ./models --flat
mdl download <repo> --dry-run        # resolve the files, print the plan, fetch nothing

--flat puts files by basename with no subfolders, which is what a llama-swap folder usually wants. --dry-run is the safest way to see how much a repo would cost you.

Three sources

Hugging Face is the default. The other two are chosen explicitly with --source, and there is no silent fallback between them, so a missing model on one hub never turns into a different download.

SourceHow it fetches
hf (default)The Hugging Face Hub API, with the HTTP or Xet engine, into the Hub-style cache or a plain directory.
modelscopeModelScope's listing API and its per-file HTTPS endpoint. Each file is checked against the sha256 the hub published; the revision defaults to master.
piratefaceA listing lookup plus a torrent fetched with a user-installed aria2c. Seeding is switched off. Needs --local-dir.
 
mdl download Qwen/Qwen3-0.6B --source modelscope --local-dir ./model
mdl download AI-ModelScope/ShareGPT-4o --source modelscope --type dataset --dry-run

MODELSCOPE_API points the ModelScope source at a mirror, and MODELSCOPE_API_TOKEN (or MODELSCOPE_TOKEN) is sent for private repositories — never to a host other than ModelScope's own. A ModelScope file with no published digest cannot be verified, so it goes to --local-dir but not into the cache.

Flags that matter

--typemodel, dataset or space.
--revisionA branch, tag or commit.
--include / --excludeGlobs, repeatable. The usual way to skip 30 GB of safetensors you do not need.
--cache-dir / --local-dirThe Hub-style cache, or a plain directory you own.
--force-downloadFetch again even if the file looks complete.
--verify auto|always|neverSize and hash checking. auto is the default.
--max-workers, --connectionsHow many files, how many connections per file.
--max-speedFor example 5M, when you share the line.
--source hf|modelscope|piratefaceWhich hub the bytes come from. Hugging Face by default.
--engine auto|http|xetTransfer engine on the Hugging Face source. HTTP is the default.
--json, --quietFor scripts.

Transfers that survive

Downloads are segmented and resumable: a transfer interrupted by sleep, a dropped connection or Ctrl+C picks up where it stopped instead of starting over. Verification compares what arrived with what the Hub says the file is.

Xet is opt-in. With --engine auto or xet the downloader tries it, and if it stalls it falls back to HTTP and skips Xet on that host for 24 hours. You do not have to think about it.

Leave it running

mdl download <repo> --detach         # enqueue and return immediately
mdl queue list | show <id> | pause <id> | resume <id> | cancel <id> | clear
mdl daemon                           # run the daemon in the foreground

The queue is persistent, so a 60 GB pull can be paused in the evening and resumed the next day without re-reading the plan.

Tokens

mdl auth login        # paste a token, or use the browser device flow
mdl auth whoami
mdl auth list
mdl auth token        # prints the active token to stdout
mdl auth logout

The token is read from --token, then HF_TOKEN / HUGGING_FACE_HUB_TOKEN, then the stored tokens. Gated repos work the same way; nothing needs the token if the repo is public.

Two licences, on purpose

  • hfd-core, the download library: Apache 2.0. Embed it in anything, commercial included.
  • Everything else, including the mdl command: PolyForm Noncommercial 1.0.0. Commercial use needs a written agreement.

That split is deliberate: the pieces other software wants to link are permissive, the tool itself is not free for commercial use.
