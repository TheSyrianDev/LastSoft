Linux

x86_64 · AppImage, deb, rpm, Arch

The AppImage runs anywhere and needs nothing installed. The script below reads /etc/os-release and installs the package your distribution actually wants. On Omarchy it installs the Omarchy build below instead of this one.

Download the AppImage
curl -fsSL https://thesyriandev.github.io/LastSoft/install.sh | sh

Script Read it before running it, as with anything you pipe into a shell. It knows Omarchy from the plain Arch distributions and picks the right package from there.

  • .deb Debian, Ubuntu, Mint, Pop!_OS
  • .rpm Fedora, RHEL, openSUSE
  • .pkg.tar.zst Arch, EndeavourOS, Manjaro

Omarchy

arch · its own build

A separate package, not the Arch one: it is compiled with Omarchy's integration, so the Omarchy and Omarchy (transparent) looks take the colours of your current theme and follow omarchy theme set, and the launcher icon is redrawn on every change. It installs the same commands, so pacman swaps it in for the plain package.

Download for Omarchy
curl -fsSL https://thesyriandev.github.io/LastSoft/install.sh | sh

Setup The package ships lastai-omarchy-setup; run it once as yourself after installing (the script does it for you). It writes the theme hook and leaves your Hyprland config alone.

Windows

x64 · zip, no installer yet

Unpack the zip anywhere and run lastai-gui.exe. The core (lastaid.exe) and the terminal client (lai.exe) are in the same folder.

Download for Windows

macOS

Apple silicon · .app, early alpha

A plain LastAI.app in a zip, no disk image to mount: unzip it and drag the app to Applications. It is signed for nothing yet, so the first launch needs right-click → Open. It starts in CI; nobody has used it day to day.

Download for macOS

Or build it

A Rust toolchain and a few minutes. This builds the core, both terminal names and the desktop app into target/release/.

git clone https://github.com/TheSyrianDev/LastAI && cd LastAI && cargo build --release

Then target/release/lai setup for the first run, and target/release/lastaid to start the core.
